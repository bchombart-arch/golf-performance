# Golf Performance

Application web de saisie de parcours de golf avec calcul des strokes gained
(étalon Broadie, PGA Tour) : saisie coup par coup sur le téléphone, bilan du
tour, Tiger 5, statistiques par secteur et module d'entraînement putting.

Tout tient dans une page : aucune donnée ne quitte l'appareil, le stockage est
celui du navigateur. Export JSON et CSV depuis l'écran Profil.

Installation sur iPhone : ouvrir l'adresse dans Safari, puis Partager →
« Sur l'écran d'accueil ». Le service worker met la page en cache, l'app
s'ouvre sans réseau.
